## 三、为什么做（问题来源）

做短视频最痛的不是"生成不出来"，而是"生成出来了但说不清为什么好/坏"。

我给自己的流水线加了质量评分器，然后发现一个反直觉现象：

**同一条评分器下，一段纯噪声画面拿到 0.6808 分，一条真实的好片只有 0.3544 分。**

原因是指标把"帧间变化小"当成了"稳定"。也就是说，**按现有质量指标去优化，画面会越调越差**——我的第一个 H3 成片就是这么变成整屏噪声的。

这个发现让我把平台改成了"评估优先"的形态：
1. 加退化检测（320×180 高频采样 + Sobel / 块方差 / 噪声比），把噪声压到 0.15
2. 把选优做成五维打分（Sface / Ssharp / Sstyle / Scomp / Sbad）
3. 所有实验数据留档，能复跑

**n=21 基准实测**：旧口径下坏片 11/13 压过好片（准确率 47.6%），修正后降到 8/13（61.9%），AUC 从 0.625 升到 0.755，Cohen's d 从 0.557 升到 1.22。
