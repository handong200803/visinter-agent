## 1. 主提示词（中文，直接可用）

```
一段约10秒、实时速度、单次连续的第一人称 POV 手持实拍视频。画面中不出现持机者本人，不出现
人物主人公、模特或自拍主体；只有环境本身，以及远处河道里的船夫和店门口整理东西的店主这两个小
人物，且都是远景或中远景，不做正面表演、不看镜头。

从第0秒到第8秒，镜头必须持续向前步行运动：不能静止、不能定格、不能像照片幻灯片、不能只有
画面局部在动而镜头不动。机位模拟真人手持手机或小型相机，沿河岸石路正常步速前行：有轻微上下
呼吸起伏和左右自然晃动，带来细微的前后起伏；运动连续平滑，不加速、不减速、不横向漂移、不剪辑、
不切镜。

画面必须有明显的前向视差：近处湿石板从脚下向后掠过，前景柳枝和垂挂的蓝印花布从镜头两侧划过，
远处的石拱桥和木屋逐渐变大。只有在最后约1秒（第9秒起），机位才自然减速并停在石桥上，俯看桥下
的乌篷船；此时水面、船、机位仍有真实运动，不能变成完全静止的照片。全程正常实时速度的缓慢行走，
不是慢动作，不是延时，不是无人机，不是稳定器滑轨，不是CG动画。

场景：浙东水乡古镇的清晨，运河水面有细小涟漪和真实倒影，空气中有薄雾和水汽。沿河是直接架在
水上的临水木廊，白粉墙面有雨水浸润的痕迹、雨痕和细小污渍，黑灰色瓦顶有真实瓦片起伏并带水光。
岸边是湿漉漉的青石板路，石缝积水反射天光，脚步踩过留下真实水痕。整体是清晨阴天自然光，暗灰略冷、
低对比，没有明信片式高饱和，没有HDR，没有美颜皮肤，没有过锐化。

时间轴（连续一镜，不是分镜）：
0-2秒：镜头从临河石岸起步，以真人步行速度缓慢向前，右下是湿石板的磨砺石纹与积水反光，
镜头有轻微起伏；左侧白墙黑瓦木屋贴着水面，右侧运河水面有微波与倒影。一片侧枝从画面上方
和右侧掠过，产生明显前景视差。
2-4秒：镜头继续前进，经过竹竿上晾晒的长条蓝印花布，布条在微风里真实轻微摆动，布料有纤维纹理、
带湿气、不僵硬、不整块飘。镜头从布条间正穿过，布条从画面边缘向后滑出，远处石拱桥轮廓逐渐变大。
4-6秒：镜头继续沿石岸前进，前方石拱桥更清晰。运河中一位船夫正站着摇橹，划着小船缓慢经过，
船不是静止道具：船身持续前进，船桨入水、出水，水面产生真实涟漪和破碎倒影。船夫身体随摇橹
有自然重心变化，衣褶和皮肤有真实纹理。镜头与船保持相对运动视差。
6-8秒：镜头继续向前，经过小店铺面，小板门、木牌匾、木纹和潮湿痕迹清晰。店内老板在店前有
细小自然动作：整理物品、抬头或轻微转身，不做夸张表演。镜头不停，继续向石桥靠近，桥面石阶
和桥栏逐渐占满画面。
8-9秒：镜头开始自然减速但仍向前，踏上石桥最后几级，手持呼吸感仍在。透过桥洞能看到乌篷船
继续从运河方向驶过，水面倒影里的白墙和布被水波打散又恢复。
9-10秒：镜头在石桥上自然停住，俯看桥下乌篷船从桥洞下穿过，画面停留约1秒；这是全片唯一
接近静止的瞬间，但水面、雾、机位仍有真实运动。

真实质感：真实湿石头、真实水面的菲涅尔反射和细微水纹、真实薄雾、真实木纹、真实瓦片、
真实布料纤维、真实皮肤纹理与毛孔，轻微自然胶片颗粒，低饱和晨光，阴影柔和。黑篷船木料有
旧漆和磨损，船篷布有褶皱，蓝印花布有布边、褶皱和轻微透光，柳叶有细碎层次（不是贴图）。
所有建筑透视、桥门、石阶、木柱、屋檐不扭曲、不变形。

声音：只有自然环境声——运河水流声、船桨划水声、湿石板上的脚步声、远处隐约人声、清晨鸟鸣、
微风拂叶声。不要音乐，不要旁白，不要夸张音效。
```

## 5. 平台参数

| 项 | 值 | 说明 |
|---|---|---|
| model | `wan2.7-t2v` | 只有它单次支持 2–15s；`wan2.2-t2v-plus` 固定 5s，做 10s 必须拼两段 → 违反「不剪镜」 |
| duration | 10 | 注册表 `mo.duration` 上限是 3s，走平台壳提交会被夹到 3s；10s 需 API 直传或调上限 |
| ratio / resolution | 16:9 / 1080P | 步行前推适合横屏；竖屏会把两侧前景视差挤掉 |
| seed | 固定值 | 便于同构图重试；不要每次换 seed 比效果 |

### 3s 样片的两个已知缺陷（都已在平台上修好开关）

1. **画面里出现女性背影主体**：因为当时走了槽位编译，`ch.subject` 的「手持机/步行」被渲染成「一个女孩」。
   → 已加 `rawPrompt` 模式（`note` 逐字作为 prompt，不经过槽位编译），并用它重写了 POV 版提示词（明确「不出现持机者、不出现主人公」）。
2. **右下角「AI 生成」水印**：云端默认打标。
   → 已加 `watermark` 开关，可在任务里传 `false`（模型不支持会 400，调用方如实上报）。

### 平台侧顺手修掉的三个真 bug

- `ds.js` 把 wan2.7 的 `durations:[2,15]` 当枚举（`includes`），3s/10s 全被判非法 → 改为「区间感知」。
- 注册表 `mo.duration` 上限 3s（本地 i2v 口径）把云端 15s 能力挡住了 → 提到 0.5–15s，默认 5s，并同步 `server/selftest.js` 的旧断言。
- `/api/jobs` 预检强行要求 `ch.subject` 非空，与 raw 模式冲突 → raw 模式改为「note 非空即可」。

## 7. 10 秒连续性的取舍（重要）

- 单次 10s 模型（wan2.7 / 可灵 10s / Veo 8s）→ 能真做到「一镜到底」，首选。
- 5s 模型拼两段 → 第二段起始帧必须用第一段末帧做 i2v，否则必然有跳变；用户明确「不剪镜、不跳」，**这条路不满足要求**。
- 若只能用 5s：把 10s 拆成「0-5s 步行」+「5-10s 接续」，用 i2v 首帧续接，并在提示词里重复「continue the same take, same lens, same walking pace」。仍是妥协方案，要如实告知。
