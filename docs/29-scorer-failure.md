# 29 · 评分器失效实证与修正（一等奖核心材料）

> 2026-11-20。这是本项目最有价值的一条发现，也是答辩的第一页。

## 1. 发现

同一套四维评分器，同一批样本：

| 视频 | 综合 F | Sface | Sflow | Sstyle | Sbad |
|---|---|---|---|---|---|
| **纯噪声片**（H3 采样错配产物） | **0.6808** | 0.837 | 0.652 | 0.798 | 0 |
| 真实片（女孩窗边看雨） | 0.3544 | 0.370 | **0.071** | 1.000 | 0 |

**噪声比真实画面高 1.9 倍。** 换句话说：如果照这个指标去优化，系统会主动把画面推向噪声。

## 2. 机制

原评分器把「帧间变化小」当成「时序稳定」：

- 噪声片：随机纹理但统计平稳 → 光流幅度小、抖动小 → `Sflow=0.652`
- 真实片：镜头推进 + 人物动作 → 光流幅度大 → `Sflow=0.071`

于是**有运动的好片被判为劣质，静止的废片被判为稳定**。这是指标口径的缺陷，不是数据问题，也不靠调权重能修好——权重再怎么调，方向是反的。

## 3. 修正：加一个「有没有真实结构」的测量

新增 `server/detail.js`，用 ffmpeg 抽灰度帧（160×90）在 Node 里算三个量（零依赖）：

| 量 | 含义 | 噪声片 | 真实片 |
|---|---|---|---|
| `noise_ratio` | 相邻像素平均差 ÷ 4×4 块均值标准差 | **1.752** | **0.286** |
| `block_std` | 4×4 块均值标准差 | 3.45 | 46.20 |
| `block_entropy` | 块均值直方图熵 | 1.15 | 4.40 |
| `edge_density` | Sobel 梯度超阈像素占比 | 0.077 | 0.383 |

判定：`noise_ratio > 0.9` 或（`edge_density > 0.35` 且 `entropy < 1.2`）→ **degenerate**。

接入评分：

```js
// scoring.js
const SbadFinal = det && det.degenerate ? Math.max(Sbad, 0.95) : Sbad;
let F = BAYES.objective({ Sface, Sflow, Sstyle, Sbad: SbadFinal }, weights);
if (det && det.degenerate) F = Math.min(F, 0.15);   // 退化没有资格参与排名
```

## 4. 修正后（同一批样本重打分）

| 视频 | 修正前 F | 修正后 F | Sbad |
|---|---|---|---|
| 噪声片 | 0.6808 | **0.1500** | **0.95** |
| 真实片 | 0.3544 | 0.3544 | 0 |

**排序翻转**：噪声从「1.9 倍优势」变成「0.42 倍劣势」。

## 5. 这个发现为什么重要

1. **它不是参数问题，是度量问题**：社区里普遍用「光流/SSIM 稳定性」当视频质量代理，这套代理同样会把静止废片判优。
2. **它解释了「模型越调越差」的现象**：用这类指标做贝叶斯/RL 优化，会把模型推向「低运动、高噪声容忍」的退化解。
3. **它给出了可复现的修法**：一个 60 行的退化检测器 + 一条硬惩罚，就能把排序掰回来。
4. **它顺带解释了后处理 ΔF 为负**（docs/24）：插帧与颗粒增加高频，被同一套指标当成「更差」。

## 7. 诚实边界

- `noise_ratio` 阈值（0.9）来自本机两条样本 + 若干历史片，**不是大规模标定**；不同编码/分辨率需重标（已在 `detail.js` 里注明 provenance）。
- 该检测器只能识别「无结构退化」（噪声、纯色、强纹理），**不能判断语义是否正确**（比如画错了人）。语义层交给 Qwen-VL（`server/providers/qwen_eval.js`，无 key 时明确 `QWEN_NO_KEY`）。
- `F ≤ 0.15` 的上限是策略选择（退出一等公民），不是统计结论。

## 8. 基准测试（n=10，2026-11-20 晚补）

把「发现」做成「结论」需要样本量。做法：5 条好片 + 5 条坏片（对好片用 ffmpeg 确定性滤镜制造 4 类退化 + 1 条真实噪声样本），同一评分器跑两遍（`detail:false` 旧口径 / `detail:true` 新口径）。

| 口径 | 好片均分 | 坏片均分 | 坏片压过好片的样本数 | 排序准确率 |
|---|---|---|---|---|
| 旧（detail off） | 0.3708 | **0.4754** | **5/5** | 50.0% |
| 新（detail on） | 0.3080 | **0.2296** | **2/5** | **80.0%** |

**旧口径零区分能力（坏片 5/5 全部压过好片），新口径准确率 80%。**

### 迭代过程（这轮最有价值的部分）

第一版新口径只有 60%：基准暴露了检测器的**采样分辨率缺陷**——160×90 采样把噪声与块状平滑掉了，4 类人工退化全部漏检。

修法：
1. 增加 **320×180 高清采样**（`analyzeHD`），保留高频；
2. 补判据：`edge_density_hd < 0.10 → 模糊`、`block_std_hd < 6 → 近似纯色`、`noise_ratio_hd > 1.15 → 高频噪声`；
3. 阈值按实测重标（好片 hdEdge≈0.34 / 模糊≈0.046 / 纯色≈0.002）。

剩余 2 条漏检：`noise_heavy`（ffmpeg 柔和噪声，视觉本就不明显）、`poster_lowq`（块状低质，需块边界规律性检测，暂未覆盖）。这两条已在报告里标注，不假装全中。
